# Interface Contract: Coder Prompt Memory Management Directives

**Branch**: `018-sandbox-memory-management` | **Date**: 2026-11-02 | **Spec**: [spec.md](../spec.md)

---

## 1. System Prompt Contract (`CODER_SYSTEM_PROMPT`)

### Preconditions
- The constant `CODER_SYSTEM_PROMPT` is defined in `src/clipper/core/prompts.py` as a non-empty string.

### Contract Requirements
1. **Rule 6 Presence**:
   The prompt text MUST contain a dedicated section for memory management specifying:
   - Mandatory inclusion of `import gc`.
   - Mandatory explicit deletion of intermediate loop buffers and arrays (`del ...`).
   - Periodic invocation of `gc.collect()`.
   - Explicit closing of all opened clips (`.close()`).
   - Explicit peak RAM threshold of 2 GB.
2. **Static AST & Content Validation**:
   Automated unit tests MUST assert that `CODER_SYSTEM_PROMPT` contains:
   - `"GERENCIAMENTO ESTREITO DE MEMÓRIA"`
   - `"import gc"`
   - `"gc.collect()"`
   - `"2 GB"`
3. **Generated Script Invariant**:
   Any Python render script generated by `coder_node` following these directives MUST parse cleanly via `ast.parse` and contain:
   - An import of module `gc`.
   - At least one call to `gc.collect()` or explicit `del` of intermediate buffer variables.
   - Resource disposal calls (`.close()`).

## 2. Retry Prompt Contract (`CODER_RETRY_PROMPT_TEMPLATE`)

### Preconditions
- The constant `CODER_RETRY_PROMPT_TEMPLATE` is defined in `src/clipper/core/prompts.py`.
- Formatted with kwargs: `attempt`, `error_diagnostic`, `previous_script`, `cut_metadata`.

### Contract Requirements
1. **Memory Directive Reinforcement**:
   The template MUST instruct the LLM during script regeneration to:
   - Retain buffer deallocation calls (`del`).
   - Retain garbage collection (`import gc`, `gc.collect()`).
   - Retain clip closures (`.close()`).
   - Enforce the 2 GB memory ceiling.
2. **Static Content Validation**:
   Automated unit tests MUST assert that `CODER_RETRY_PROMPT_TEMPLATE` contains:
   - References to buffer cleanup and `gc.collect()`.
   - The 2 GB memory limit requirement.
